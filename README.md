# Claude Synolia — Plugin Marketplace

Public **Claude Code** plugin marketplace by Synolia / Blackbird for accessible development following RGAA criterias.

- **Marketplace**: `rgaa-accessibility`
- **Repo**: `blackbird-agency/rgaa-accessibility-marketplace`

## Available plugins

| Plugin | Content |
|--------|---------|
| `accessibility` | Accessibility skills (ARIA, RGAA) |

## Installation

### Enable plugins per project

In the project's `.claude/settings.json`:

```json
{
  "enabledPlugins": {
    "accessibility@rgaa-accessibility": true
  }
}

```
